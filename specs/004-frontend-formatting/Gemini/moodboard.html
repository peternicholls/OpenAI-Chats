Zipfian Hit Ratio

For the probability of a cache hit given a Zipf-like distribution of requests, the distribution is calculated as follows:

p(H) = \frac{\sum (1 / i^\alpha)}{\sum (1 / n^\alpha)}

Here is how you might approximate this distribution via code:

def calculate_hit_ratio(cache_size: int, total_items: int, alpha: float = 1.0) -> float:
    """Calculates the theoretical hit ratio using a Zipfian distribution."""
    denominator = sum(1.0 / (i ** alpha) for i in range(1, total_items + 1))
    numerator = sum(1.0 / (i ** alpha) for i in range(1, cache_size + 1))
    
    return numerator / denominator
