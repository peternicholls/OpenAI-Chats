Decision matrix

What each direction implies for the sprint tasks
Decision area Quiet Ledger Editorial Transcript Precision Product
Transcript typography
T005, T014, T014a, FR-001/013		 Sans-led, compact, excellent for long archives and code-heavy sessions. Best reading quality and hierarchy; most differentiated. Clear and familiar, but less memorable unless spacing is refined.
Thinking/search block
T005a, FR-016–017, SC-010		 Subtle dashed disclosure. Lowest noise, lowest salience. Margin-note style. Honest and elegant, slightly more bespoke. Strong pill/card disclosure. Most obvious and easiest to expand/accessibly target.
Date separators + header
T005b, T013a, FR-018–020		 Very restrained separators; metadata treated as archive facts. Date feels like editorial chaptering; highest sense of narrative flow. Metadata chips make dates/count/model explicit and easy to scan.
Attachment + image modal
T005c, T020, FR-021, SC-012		 Thumbnail stays quiet; modal should do the heavy lifting. Thumbnail behaves like an inline figure; modal can feel premium. Most implementation-aligned with current component model; clear metadata hierarchy.
Fallback presentation
T005, T026, T027, FR-005		 Soft notices that avoid panic, good for legacy archive feel. Readable side-notes; best if fallback frequency is low. Most explicit that the renderer degraded gracefully, but risks adding chrome.
Mobile behavior
FR-007, T014, T027		 Adapts cleanly because it depends on spacing more than framing. Needs careful type scaling so serif reading stays comfortable at 320–390px. Requires the most discipline to prevent stacked cards from feeling dense on phones.
Most balanced hybrid Use Quiet Ledger as the baseline transcript structure, borrow Editorial Transcript typography for assistant markdown answers, and adopt Precision Product for image modal / fallback / focus-state affordances.
Questions to resolve before implementation Decide whether the product should feel primarily archival, reading-first, or software-polished; that single decision will cascade into T013/T014 styling, T005a disclosure prominence, and how assertive the attachment + fallback blocks should be.
